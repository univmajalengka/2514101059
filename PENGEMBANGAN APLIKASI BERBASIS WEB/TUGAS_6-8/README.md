Tugas Pertemuan 6-8.
1. Membuat fungsi/prosedur hitungDiskon().
2. Fungsi menerima parameter berupa total belanja.
3. Jika belanja ≥ Rp100.000, diskon 10%.
4. Jika belanja ≥ Rp50.000, diskon 5%.
5. Jika belanja di bawah Rp50.000, tidak mendapat diskon.
6. Mengembalikan nilai diskon untuk menghitung total pembayaran.
